# Vendored test vectors

Official known-answer test vectors, used by `lake exe hash-kat`. Each file is copied unmodified
from the source below; the SHA-256 of every file is listed so that the copies can be checked.

## `nist-cavp-shs/`: NIST CAVP, Secure Hash Standard (FIPS 180-4)

- **Source:** NIST Cryptographic Algorithm Validation Program, "SHA Test Vectors for Hashing
  Byte-Oriented Messages",
  <https://csrc.nist.gov/CSRC/media/Projects/Cryptographic-Algorithm-Validation-Program/documents/shs/shabytetestvectors.zip>
  (downloaded 2026-10-11; archive SHA-256
  `929ef80b7b3418aca026643f6f248815913b60e01741a44bba9e118067f4c9b8`). Generated by CAVS 11.1.
- **Licence:** a work of the U.S. Government, not subject to copyright in the United States
  (17 U.S.C. §105).
- **Format and procedure:** the Secure Hash Algorithm Validation System (SHAVS),
  <https://csrc.nist.gov/CSRC/media/Projects/Cryptographic-Algorithm-Validation-Program/documents/shs/SHAVS.pdf>.
  `ShortMsg` and `LongMsg` files list messages and digests; `Monte` files are the pseudorandom
  (Monte Carlo) test of SHAVS §6.4.
- **Included:** SHA-224, SHA-256, SHA-384, SHA-512, SHA-512/224 and SHA-512/256 (SHA-1 is not
  specified by this library).

## `nist-cavp-sha3/`: NIST CAVP, SHA-3 Standard (FIPS 202)

- **Source:** NIST Cryptographic Algorithm Validation Program, "SHA-3 Hash Function Test
  Vectors for Hashing Byte-Oriented Messages",
  <https://csrc.nist.gov/CSRC/media/Projects/Cryptographic-Algorithm-Validation-Program/documents/sha3/sha-3bytetestvectors.zip>
  (archive SHA-256 `cd07701af2e47f5cc889d642528b4bf11f8b6eb55797c7307a96828ed8d8fc8c`), and
  "SHA-3 XOF Test Vectors for Byte-Oriented Output",
  <https://csrc.nist.gov/CSRC/media/Projects/Cryptographic-Algorithm-Validation-Program/documents/sha3/shakebytetestvectors.zip>
  (archive SHA-256 `debfebc3157b3ceea002b84ca38476420389a3bf7e97dc5f53ea4689a16de4c7`). Both
  downloaded 2026-10-12. Generated by CAVS 19.0.
- **Licence:** a work of the U.S. Government, not subject to copyright in the United States
  (17 U.S.C. §105).
- **Format and procedure:** the SHA-3 Validation System (SHA3VS),
  <https://csrc.nist.gov/CSRC/media/Projects/Cryptographic-Algorithm-Validation-Program/documents/sha3/sha3vs.pdf>.
  `ShortMsg`, `LongMsg` and `VariableOut` files list messages and outputs; `Monte` files are the
  pseudorandom tests of SHA3VS §6.2.3 (SHA-3) and §6.3.3 (SHAKE). The files have CRLF line
  endings, as distributed.
- **Included:** SHA3-224, SHA3-256, SHA3-384, SHA3-512, SHAKE128 and SHAKE256 (all files of both
  archives).

## `blake2/`: the BLAKE2 team's known-answer tests

- **Source:** `testvectors/blake2-kat.json` of the reference repository
  <https://github.com/BLAKE2/BLAKE2> at commit `ed1974ea83433eba7b2d95c5dcd9ac33cb847913`
  (downloaded 2026-10-12), copied unmodified.
- **Licence:** CC0 1.0 Universal (the repository's `COPYING`).
- **Format:** a JSON list of records with fields `hash`, `in`, `key` and `out`. `hash-kat` checks
  the 512 `blake2b` and 512 `blake2s` records (unkeyed and keyed, messages of 0 to 255 bytes);
  the tree and XOF variants (`blake2bp`, `blake2sp`, `blake2xb`, `blake2xs`) are not specified by
  this library.

## `eip-152/`: the BLAKE2b `F` precompile

- **Source:** the "Test Cases" section of EIP-152, <https://eips.ethereum.org/EIPS/eip-152>
  (`EIPS/eip-152.md` of <https://github.com/ethereum/EIPs>, downloaded 2026-10-12, SHA-256
  `5ef0b093f024a65ea850c2f0b431a6c636a5b391d24b9183755e17a8eaeea913`). Vectors 0–8 were
  extracted into `vectors.txt` without changing any input, output or message.
- **Licence:** CC0 (EIP text).
- **Note:** vector 8 asks for 2³² − 1 rounds. It is skipped by `hash-kat`, which would take far
  too long on a specification; the `F` function is otherwise identical for every round count.
